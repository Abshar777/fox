# Mentor portraits

Drop portrait photos here as `01.jpg` … `05.jpg` (portrait crop, ideally
900×1200 or larger). The mentors grid picks them up automatically.

Until a file exists, each card falls back to a generated crest tile — no
broken images. Mentor names live in `components/mentors.jsx`; set the
`name` field and the card shows it instead of the role title.
